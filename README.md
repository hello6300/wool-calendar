# 羊毛日历（Wool Calendar）

记录「薅羊毛」活动的 Android App：月历 + 列表，按设备 / 平台分类，支持到点提醒、从手机日历导入、WebDAV 多设备同步。

数据默认只留在本机，不接入任何第三方账号或服务器。

## 功能

**月历与记录**
- 月历网格按天展示，圆点按状态着色（待参与 / 已参与 / 已到账 / 已过期），每格最多 3 个
- 每条记录含：平台、标题、日期、开始 / 结束时间、状态、活动链接、详情、备注、预计收益、设备
- 结束时间早于开始时间按次日算（如 20:00–01:00）；当天列表按开始时间排序
- 当日列表顶部自动汇总「N 条 / 合计 ¥x.xx」
- 展开卡片可看详情，用 chip 直接改状态；删除有二次确认

**到点提醒**
- 每条记录可在开始、结束时刻各弹一条系统通知，点通知回到当天日历
- 重启手机或重装后自动重排全部未来提醒，编辑记录会先取消旧提醒再重排
- 自检页可查通知权限、精确闹钟、时区、待发条数，并可发测试通知 / 排一条 1 分钟后的提醒

**设备分类**
- 首次启动按机型自动识别本机（如「Redmi K30 Pro」），可改名、可新增平板 / 备用机 / 工作机
- 日历圆点、当日列表、收益合计都能按设备筛选
- 删除设备不删记录，记录迁回本机设备并提示条数；本机设备不可删

**自定义常用平台**
- 平台 chip 可增删改，首次启动按系统语言预置一套（京东 / 淘宝 / 拼多多 / 抖音 / 快手 / 美团 / 支付宝 / 银行 / 其他）
- 改名或删除平台不会改动历史记录的已填内容

**从手机日历导入**
- 手动选范围（今天 / 未来 7 天 / 本月 / 未来 30 天 / 自定义），点「提取」才读取，绝不自动扫描
- 只读系统日历，不新增、不修改、不删除任何活动
- 已导入的活动会标记「已导入」并置灰，重复活动每次实例可分别导入
- 可指定这批活动归到哪台设备名下

**WebDAV 多设备同步**
- 兼容坚果云、Nextcloud、群晖、飞牛 fnOS 等任意 WebDAV 网盘，不依赖自建后端
- 内置远端目录浏览，点选目录即生成路径，不用猜各家前缀
- 双向合并：按记录 id 取并集，同 id 取较新一方；删除写墓碑，另一台设备的旧副本不会把记录复活
- 状态卡显示「云端拉到 / 上传 / 更新 / 删除」四项计数
- 每天首次同步前自动把云端留一份备份，备份份数可设「3 / 7 / 14 / 30 / 不限」
- 可从某天的备份恢复（恢复前另存一份快照作为退路），恢复同时写回云端

**其他**
- 中文 / 英文双语
- 同步密码存系统加密存储（Android Keystore），不落明文、不进日志
- 远端文件缺本 App 的标记时直接中止，不会覆盖别人的文件

## 更新点

### 2026-11-18
- **修复 release 包到点通知不生效**（debug 包正常、release 包静默失败）：构建裁掉了 Gson 需要的泛型签名，已补 keep 规则
- **备份「只保留最近 N 份」可配置**：3 / 7 / 14 / 30 / 不限，默认 7；同步成功后自动清理更旧的备份，清理失败不影响同步结果
- **「立即同步」固定在同步设置页底部**，不再需要滚到表单末尾；主界面当天列表下拉即可同步
